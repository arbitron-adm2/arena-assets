# Бандлы и ассеты клиента 1.61.7

Всё, что клиент (Flash/AS3, 1.61.7) тянет с CDN, разложено по типам так, чтобы по этому
набору можно было пересобрать игру или портировать её на другой рантайм.

Разобрано JPEXS FFDec 26.4.0.

## Состав

| каталог | что | объём |
|---|---|---|
| `swf/1.61.7/` | оригинальные SWF как есть: клиент, прелоадер, 79 ассет-паков, звуковые паки, аватары | 100 файлов, 28 МБ |
| `packs/1.61.7/` | те же SWF, разобранные по типам ресурсов | 54 772 файла, 695 МБ |
| `data/1.61.7/` | XML-данные: локализация ru/ua/en, конфиги ресурсов, чат, соцсеть | 68 файлов, 2,3 МБ |
| `client/1.61.7/` | декомпилированный ActionScript клиента и прелоадера | 2 863 файла, 14 МБ |
| `protocol/` | реверс протокола: фрейминг, кодек, структуры, каталог эндпоинтов | 14 файлов |
| `tools/` | скрипты экспорта, докачки и сборки манифеста | — |
| `manifest.json` | инвентарь: пути, размеры, sha256 каждого SWF, счётчики по пакам | — |

Внутри `packs/1.61.7/<пак>/`:

```
shapes/*.svg     векторные шейпы — вся графика игры (17 926 файлов)
*.png            те же шейпы в растре + растровые картинки (17 480)
sprites/<Name>/frames.webp  готовые анимации всех паков (10 388 animated WEBP)
sounds/*.mp3     звуки и музыка (156)
fonts/*.ttf      шрифты (50)
scripts/*.as     ActionScript, лежащий внутри пака (6 909)
binaryData/      DefineBinaryData
symbolClass/     CSV: characterId → имя класса
texts/*.txt      статические тексты из таймлайнов (1 778)
```

Сопутствующие индексы:

* `packs/1.61.7/_symbols.json` — `пак → [characterId, класс]` (3 912 записей).
* `data/1.61.7/configs.json` — `resconfig.xml`, `bosses_config.xml`, `battle_stuff_config.xml`,
  разобранные в JSON (50+33+3 библиотеки, 4 099 ресурсов).
* `data/1.61.7/resource-map.json` — `класс → {библиотека, characterId, svg/png/sprite}` для 3 991 ресурса
  (3 304 с готовым файлом) и 151 звука. Это главный вход для порта: по игровому имени сразу видно, откуда брать графику.

## Что где лежит

* **Персонажи** — `common/chars/{alien,boar,boxer,cat,demon,dragon,rabbit,rhino,robot,zombie}`.
* **Боссы** — `common/bosses/*` (33 пака, по одному на босса).
* **Предметы/оружие/шляпы** — `common/objects/*` (21 пак, включая `weapons`, `hats`, `artifacts`, `weapon_upgrades`).
* **UI и меню** — `common/general/*` (`wormix_ui`, `arena`, `news`, 4 сезонных `mainMenu-*`).
* **Комнаты** — `common/rooms/*` (арена, крафт, клан, достижения, гонки).
* **Звук** — `storage/sound/sounds_1.53` (151 эффект, имена сохранены: `WoodClubAttack.mp3`, …)
  и `storage/sound/music_theme_1` (2 трека меню).
* **Аватары** — `storage/social/vkontakte/avatar/Avatar_*.swf` (17 штук).

## Как это воспроизвести

```bash
tools/export-packs.sh 1.61.7      # разбор всех SWF (FFDec; путь в $FFDEC)
tools/fetch-storage.sh            # докачка storage/sound и аватаров с CDN
python3 tools/build-manifest.py   # пересборка manifest.json
python3 tools/fix-shape-png.py 1.61.7   # добор PNG там, где FFDec падал на пустых шейпах
```

## Как забрать конкретный символ

```bash
# 1. класс -> пака и characterId
jq '.resources.WoodClubAttack' data/1.61.7/resource-map.json

# 2. если готового файла нет — достать из пака по id
java -jar ffdec.jar -format sprite:webp_animated -selectid 1234 \
     -export sprite out/ swf/1.61.7/data/common/objects/weapons.swf
```

## Особенности формата (важно при портировании)

1. **Графика векторная.** Растр (`images/`) есть только у фонов и фото. Для порта берите SVG,
   для прототипов — PNG рядом.
2. **Анимации живут в таймлайнах SWF.** Готовые анимации персонажей и боссов выгружены
   в `sprites/<DefineSprite_<id>_<Class>>/frames.webp` (animated WEBP); остальные паки можно
   добрать тем же скриптом. Кадры по отдельности: `-format sprite:gif`.
3. **Код обфусцирован secureSWF**: имена классов/пакетов вида `§8".&!§`; читаемые остались
   только у `ru.pragmatix.wormix.*` и библиотек (greensock, adobe, vk/ok API).
4. **Локализация — плоские XML** (`data/lang/*_ru|ua|en.xml`), UTF-8.
5. **Ресурсные конфиги** (`resconfig.xml`, `bosses_config.xml`, `battle_stuff_config.xml`) —
   главный маппинг «игровой id → класс/пак/звук»; в них же пути `../storage/...`.
6. **Звук не встроен в паки**: `DefineSound` в игровых SWF нет (0 тегов), всё аудио —
   отдельные `storage/sound/*.swf`, которые подгружаются лениво.
7. **Клиенту нужен сервер** (TCP-протокол + ключ авторизации): ассеты покрывают картинку,
   звук, шрифты и данные, но не игровую логику. См. `protocol/`.

## Чего нет / не удалось достать

* `storage/icons/*` — nginx отдаёт 403 на листинг, а имена генерируются из данных аккаунта;
  пробные пути (`icons/races/<BossName>.png`) дают 404. Известен только префикс и набор подпапок
  (`common/ races/ levelup_ru/ levelup_en/ bonus/ clan/ battle/ rank/`).
* `storage/levels/map<version>.swf` — уровни; файлы по этому шаблону не найдены (404),
  вероятно другой хост/версия каталога. Путь и шаблон имени зафиксированы в
  `client/1.61.7/as3/…/§3%b§.as` (`../storage/levels` + `map{version}.swf`).
* Серверная логика и содержимое БД — вне ассетов.

## Чувствительные данные

Из выгрузки вырезаны статические секреты протокола (в `protocol/` и в исходниках
клиента они заменены на `<REDACTED_PROTOCOL_SECRET>` / `<REDACTED_CLIENT_SECRET>`).
Сама схема подписи (`md5(body + secret)` + 16-байтный трейлер) описана и воспроизводится,
значение секрета — нет.

## Что лежит в git, а что нет

В репозитории: исходные SWF (`swf/`), декомпилированный код клиента (`client/`),
данные и индексы (`data/`), реверс протокола (`protocol/`), скрипты (`tools/`),
`manifest.json`.

Не в git: `packs/` (≈700 МБ растровых и звуковых выгрузок) — они полностью
воспроизводятся из `swf/` скриптами `tools/export-packs.sh` и `tools/export-sprites.sh`.
